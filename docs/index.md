# B-CAD documentation

**Current stage: experimental first CAD slice and contributor hub.** A local workbench and Blender adapter can exercise a small set of exact primitives. There is no production release or broad CAD feature parity.

B-CAD is an open project to build a parametric mechanical CAD environment inside Blender. These documents explain the intended system and how to help make it real.

## How to read these docs

**Implemented** means code and verification evidence exist in the repository. **Proposed** means a design direction is under discussion. **Planned** means a roadmap item has not been delivered. The prototype's exact scope and experimental contracts are recorded in [ADR 0002](decisions/0002-first-prototype.md).

The architecture and roadmap are living documents. Source materials can suggest a direction; they do not silently approve a dependency, certify Blender compatibility, or turn a feature into a working one.

Browse these pages on GitHub, or use the website's [documentation search](https://ramses13th.github.io/B-CAD/search.html) to find a topic or roadmap task.
